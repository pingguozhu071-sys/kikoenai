# kikoenai
Unofficial desktop client for Kikoeru servers (asmr.one compatible), built with Electron, Vue 3 and Material 3. Offline playback for downloaded works, resumable and pausable downloads, folder-scoped playlists, subtitle auto-binding (LRC/SRT/ASS/VTT), desktop lyrics, taskbar controls, an install wizard, and an Animeko-inspired UI. Windows-first.
