# Kikoenai

[English](README.md) / **简体中文**

面向 **Kikoeru** 兼容服务器的第三方、非官方桌面客户端，基于 Electron + Vue 3 + Material 3，优先支持 Windows。

> **与 Kikoeru、kikoeru-express 以及任何内容站点均无隶属关系。**
> 本仓库不包含任何音频、视频、字幕或图片内容，不包含任何凭据，也没有遥测。
> 它只是一个客户端：服务器由你自己填写，且应当是你有权使用的服务器。

---

## 这是什么

Kikoeru 系服务器提供一套 REST 接口，用于浏览同人音声作品、串流播放与读取字幕。Kikoenai 把这套接口包进一个桌面壳里，做成接近原生播放器的体验：离线下载、重启后续传、字幕自动挂载、桌面歌词、Windows 安装向导。

它**不是**服务器、不是爬虫、不是任意站点的下载器，也不分发任何人的库。

## 功能

### 浏览与发现
- 作品墙：榜单徽章、字幕/R18 标记、评分与销量。
- 搜索支持命名空间语法：`$tag:值$`、`$va:值$`、`$circle:值$`、`$-tag:排除$`、引号短语、纯文本 `-排除`。
- 命名空间补全、最近搜索、排序菜单、无限滚动。
- 按 标签 / 社团 / 声优 分类浏览。
- 推荐页：基于本地生成的匿名画像。
- 详情页：标签投票、收藏、加入播放列表。

### 播放
- 音频与视频统一用单个 `<video>` 元素；同一文件夹内不按扩展名过滤。
- 顺序 / 列表循环 / 单曲循环 / 随机，播放队列，倍速 0.75×–2×，音量、静音。
- 睡眠定时（30 分钟），数据层另有“播完当前曲停止”。
- 播放位置记忆：每 5 秒保存，载入时恢复。
- 本地优先：已下载的音轨直接读磁盘；本地文件失效时自动回退在线一次并保留位置。
- 视频作品会打开固定尺寸的视频窗口（可拖动进度条、可手动全屏）；纯音频不会弹出。

### 字幕与歌词
- 支持 LRC、SRT、ASS/SSA、VTT 与纯文本台本。
- 编码探测：UTF-8、Shift-JIS、GBK、Big5、EUC-KR。
- 自动匹配**只在音轨所在的文件夹内**进行，特典/闹铃文件夹不会串到正片字幕；跨文件夹只接受“唯一完全同名”。
- 支持按音轨手动绑定并记住选择。
- 全局偏移（±0.5 秒）与逐行偏移数据。
- 置顶桌面歌词窗口，可移动到另一块显示器。

### 下载与离线
- 下载作品中所有可下载文件：音频、视频、字幕、图片、PDF。
- 并发 1–5，由主进程队列真正限流。
- 暂停 / 继续、HTTP Range 续传、ETag 变化时整文件重下。
- 任务列表落盘，重启后未完成任务自动续传。
- 同名文件自动加 ` (n)`；清洗 Windows 保留名与非法字符。
- 下载地址必须是公网 http(s)：默认拒绝环回、私有与保留地址，仅对你自行配置的服务器主机放行。

### 桌面集成
- 无边框窗口、自绘按钮、平滑全屏动画。
- 系统托盘：显示/隐藏与播放控制。
- 全局媒体键、Windows 任务栏缩略图按钮。
- 单实例；关闭窗口可配置为收进托盘或直接退出。
- 安装向导（快捷方式 + 应用和功能条目）或纯便携目录。
- 按天写入运行日志。

## 环境要求

- Windows 10/11（x64）。界面是 Electron，其他平台未测试。
- 一个可通过 HTTP(S) 访问的 Kikoeru 兼容服务器（例如自建的 `kikoeru-express`）。
- 从源码构建需要 Node.js 20+ 与 npm。

## 安装

### 安装向导
1. 下载发布压缩包，解压到任意位置。
2. 运行 `安装.bat`（或 `Kikoenai.exe --install`）。
3. 选择安装目录，等待复制完成，可勾选立即启动。

安装向导会创建桌面与开始菜单快捷方式，并在「应用和功能」里登记卸载项。卸载只删程序与快捷方式，已下载作品与账号数据保留。

### 免安装
直接运行解压目录里的 `Kikoenai.exe`。除 `%APPDATA%\KikoeruPC`（设置、任务列表、日志）与下载目录外，不写任何位置。

> 可执行文件没有代码签名，首次运行可能触发 SmartScreen 提示；确认来源可信时选择「更多信息 → 仍要运行」。

## 从源码构建

```bash
npm ci
npm run typecheck
npm test
npm run package
```

`npm run package` 会构建前端、把 Electron 运行时复制到 `release/Kikoenai`、重命名可执行文件、写入版本信息，并校验打进包里的 `dist/index.html` 与刚构建的产物哈希一致。输出是一个便携目录。

开发模式：

```bash
npm run dev          # Vite 开发服务器
npm run app:dev      # Electron 加载开发服务器
```

## 配置

所有设置都在应用内：**设置 → 服务器与网络 / 下载 / 关闭窗口时 / 日志**。

- **服务器地址** — 任意 http(s) 基础地址。默认填了一个公开的 Kikoeru 兼容站点，开箱即用；随时可改成你自己的服务器。改完需要重启生效。
- **上游代理** — `自动`（缓存 → 本机常见端口 → 系统 → 直连）、`系统代理`、`直连`，或自定义规则，例如 `http://127.0.0.1:7897` / `socks5://127.0.0.1:1080`。
- **环境变量** — `KIKOERU_TARGET`、`KIKOERU_PROXY` 的优先级高于界面设置。

### 数据位置

| 路径 | 内容 |
| --- | --- |
| `%APPDATA%\KikoeruPC\config.json` | 服务器地址、代理模式、下载设置、关闭行为 |
| `%APPDATA%\KikoeruPC\downloads.json` | 下载任务列表（用于续传） |
| `%APPDATA%\KikoeruPC\logs\YYYY-MM-DD.log` | 主进程与渲染层日志 |
| `%APPDATA%\KikoeruPC\Local Storage` | 登录令牌、播放位置、字幕绑定 |
| 你选择的下载目录 | 下载的文件，默认每部作品一个 `RJxxxxxxx` 子目录 |

## 快捷键

| 按键 | 行为 |
| --- | --- |
| `空格` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5 秒（`Shift` 为 30 秒） |
| `↑` / `↓` | 音量 |
| `M` | 静音 |
| `N` / `P` | 下一首 / 上一首 |
| `/` | 跳到搜索 |
| `F11` | 全屏切换 |
| `Esc` | 退出全屏 / 关闭正在播放页 / 关闭视频窗口 |

## 架构说明

- 渲染层由自定义 `app://` 协议提供，与其自身的代理端点同源，因此不需要服务器放开 CORS。
- `/kapi/*` 由主进程转发到配置的服务器。重定向会在每一跳重新校验目标；最终落到环回/私有地址的响应会被丢弃。
- `/kmedia?u=` 走同一套校验，用于读取字幕等文本资源。
- `/local?p=` 只读地提供已下载文件，限制在下载根目录内，并支持 HTTP Range 以保证拖动进度可用。
- 凭据不会离开本机；没有统计、没有崩溃上报、没有自动更新通道。

## 疑难排查

**视频有画面没声音。** 音轨大概是 AC-3、E-AC-3 或 DTS，Chromium 不解这些编码。应用会检测并提示具体编码；把文件下载下来用支持该格式的播放器打开即可。

**改了服务器后什么都加载不出来。** 重启应用（设置 → 服务器与网络 → 保存 → 重启生效）。服务器地址是主进程启动时读取的。

**挂了代理还是下载失败。** 把代理模式显式设成「自定义」而不是「自动」，然后重启。

**别的问题。** 打开 **设置 → 日志 → 打开目录**，看当天的文件；启动那一行会记录当前的服务器、代理和模式。

## 已知限制

- 以 Windows 为主；代码是跨平台 Electron，但只在 Windows 上验证过。
- 没有代码签名，也没有自动更新；更新靠手动替换目录。
- 字幕逐行偏移只有数据层，暂无界面入口。
- 睡眠定时界面只提供 30 分钟一档。
- 播放列表支持读取/新建/删除，没有重命名。
